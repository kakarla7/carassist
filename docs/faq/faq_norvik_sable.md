# FAQ: Norvik Sable

A: Every 12,000 miles.

Q: What oil does the Norvik Sable use, and how much?
A: 0W-20, 4.0 liters, changed every 7,500 miles.

Q: What tire pressure should I use on the Norvik Sable?
A: 34 psi for size 205/60R16.
