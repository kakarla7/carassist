# SB-2025-04: 2025 Aria requires an AGM battery

The 2025 Arden Aria uses a Group 48 AGM battery, part BAT-48A. Do not fit the flooded Group 35 battery (BAT-35) used on the 2024 Aria. Using the wrong battery type can cause charging problems.
